### Project Details

#### 1. DreamLab — Latent Diffusion Transformer for Text2Video Generation
- **Category:** `AI & ML`
- **Lead Developer:** Anmol Agarwal
- **Image:** `assets/anmol_projimage.png`
- **Tech Stack:** `GenAI`, `Python`, `PyTorch`, `Diffusion Transformer`, `Autoencoders`, `CLIP`
- **Description:**
  > A smaller-scale implementation of a text-to-video generation model, inspired by OpenAI's Sora. Designed and experimented with various autoencoder architectures, focusing on minimizing quality loss through a combination of perceptual and reconstruction losses. Implemented the denoising process using a Diffusion Transformer (DiT) architecture with spatio-temporal attention and text conditioning via CLIP embeddings.
- **Repository:** `https://github.com/anm-ol/DreamLab`
- **Documentation:** `https://anm-ol.github.io/projects.html`
- **Live Demo:** `None`

#### 2. Electro-Lithography System (ELS)
- **Category:** `IoT & Hardware`
- **Lead Developer:** Mohammad Ruvaifa
- **Image:** `assets/ELS_image.png`
- **Tech Stack:** `Python`, `Holmarc Motor Controllers`, `Source Measurement Unit (SMU)`, `Micropositioners (XYZ stage)`
- **Description:**
  > A custom-built Electro-Lithography system that enables micron-level precision probe movement with real-time Z-axis feedback. Designed to facilitate patterning on surfaces at micro and nano scales by detecting probe-and-sample contact through electrical current feedback.
- **Repository:** `https://github.com/Ruvaifa/electro-lithography-system`
- **Documentation:** `https://github.com/Ruvaifa/electro-lithography-system/blob/main/README.md`
- **Live Demo:** `None`

#### 3. Sim3D — Realtime Cloth Simulation & Physics Engine
- **Category:** `3D Rendering`
- **Lead Developer:** Anmol Agarwal
- **Image:** `assets/sim3d.png`
- **Tech Stack:** `C++`, `OpenGL`, `Simulation`, `Computational Graphics`, `Mass-Spring System`, `Phong Shading`, `Batch Rendering`, `Particle System`, `Collision Detection`, `ImGui`
- **Description:**
  > A 3D physics simulation engine developed from scratch in C++ using OpenGL. Features a mass-spring system for textured cloth simulation, advanced lighting with Phong shading, and efficient batch rendering. Includes a particle system with uniform grid-based collision detection and an interactive scene editor built with ImGui.
- **Repository:** `https://github.com/anm-ol/sim3d`
- **Documentation:** `https://anm-ol.github.io/sim3d.html`
- **Live Demo:** `None`

#### 4. PGNTA: 17 DOF Humanoid Arduino Robot
- **Category:** `Robotics`
- **Lead Developer:** Prashant Gupta
- **Image:** `assets/PGNTA_image.png`
- **Tech Stack:** `Robotics`, `Controls`, `ESP32`, `Arduino`, `Servo Motors`
- **Description:**
  > PGNTA is a 17 Degree of Freedom (DOF) humanoid robot powered by an ESP32 microcontroller. Built primarily from laser-cut wooden plywood, it combines servo motors, sensors, and custom-designed joints to achieve functional bipedal walking and humanoid posture dynamics.
- **Repository:** `None`
- **Documentation:** `https://rebelpg.github.io/project/`
- **Live Demo:** `None`
